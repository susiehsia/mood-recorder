# 每日记录工具

多模板情绪与健康追踪工具，纯前端单页应用，在浏览器中直接运行。

**在线地址：** https://susiehsia.github.io/mood-recorder/

---

## 模板

工具内置 4 个独立模板，各自记录互不干扰：

| 模板 | 字段数 | 适用场景 |
|------|--------|----------|
| 🌸 **经前情绪** | 完整版 14 / 极简版 5 | PMDD 症状追踪，含周期、情绪、睡眠等 |
| 🤕 **头痛** | 10 | 头痛类型、位置、时长、诱因、服药记录 |
| 🤧 **感冒** | 10 | 体温、喉咙痛、咳嗽、抗原、全身酸痛等 |
| 🏃 **运动** | 8 | 运动类型、时长、强度、运动后疼痛、拉伸 |

每个模板的字段说明可通过右下角悬浮 `?` 按钮随时查看。

---

## 功能

### 📝 今天
- 模板标签切换，点哪个填哪个
- **经前情绪**支持完整版/极简版一键切换
- 保存时自动保存所有已填模板
- 支持回填历史日期

### 📅 日历
- 月视图，有记录的日子显示彩色小点（不同颜色代表不同模板）
- 点击任意一天查看/编辑/删除记录
- 多个模板的数据在同一天以不同颜色区分

### 📊 统计
- 情绪趋势折线图
- 支持选择单个模板查看，或「综合」模式查看所有模板数据叠加
- 近 7 天 / 30 天 / 90 天 / 全部切换
- 自动计算各维度平均值

### ⚙️ 管理
- 导出数据（JSON / CSV）
- 导入数据（从 JSON 恢复）
- 批量编辑（按模板 + 日期范围批量更新字段）
- 文件备份（下载 JSON 到手机/电脑保存）
- 打分参考（悬浮 ? 按钮，每个模板的字段说明）

## 使用方式

1. 打开 https://susiehsia.github.io/mood-recorder/
2. 手机浏览器添加到主屏幕，像 App 一样使用
3. 每天选择需要的模板填写记录
4. 数据自动保存在浏览器缓存中
5. 定期备份：管理 → 保存到文件

---

## 打分规则

| 分数 | 含义 |
|:---|:---|
| 1 | 无 |
| 2 | 极轻 |
| 3 | 轻 |
| 4 | 中 |
| 5 | 重 |
| 6 | 极重 |

**月经：** 0=无 1=点滴 2=少 3=中 4=多  
**极简版总体感受：** 1-10，10=最好

---

## 数据说明

数据存储在浏览器本地缓存（localStorage），不涉及服务器。
旧版本数据（单模板格式）首次打开时自动迁移到多模板格式。

---

## 更新方式

直接替换 GitHub 仓库中的 `index.html` 文件即可：

1. 打开 https://github.com/susiehsia/mood-recorder
2. 点 Add file → Upload files
3. 拖入新的 index.html 替换
4. Commit changes
5. 等 1~2 分钟自动部署
