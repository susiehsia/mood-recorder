💡 使用提示

📌 数据存储在浏览器本地 (localStorage)，清除浏览器缓存会丢失数据，请定期导出备份。

📌 手机和电脑用不同的浏览器时数据不互通，如需跨设备同步请导出 JSON 后在另一台设备导入。

📌 设置每日定时提醒：

  1. 打开 Windows 搜索 → 输入"任务计划程序"并打开
  2. 右侧"创建基本任务" → 名称填"每日记录提醒"
  3. 触发器选"每天" → 设置时间（如 21:00）
  4. 操作选"启动程序" → 程序填你的浏览器路径
  5. 参数填此 HTML 文件的完整路径

统一打分规则

字段说明

烦躁易怒、什么都看不顺、想发火
